Sobre o Projeto

Mais Português é um projeto acadêmico desenvolvido como trabalho de Engenharia de Software, com o objetivo de criar uma plataforma educacional eficiente e acessível para o aprendizado da língua portuguesa.

O projeto implementa boas práticas de desenvolvimento, incluindo arquitetura MVC, testes unitários, documentação completa e deploy seguro.
